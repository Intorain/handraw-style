# 🎨 HandRaw Style Studio (独立可视化手绘创作客户端)

> **零门槛、零依赖：无需掌握复杂 CLI 或安装 Skill，双击即可一边浏览 331 种手绘画廊，一边文生图、图生图与智能改图。**

---

## 🌟 核心特色与功能

1. **🎨 看着画廊生图与改图**
   - **画廊即选即用**：全景浏览 **331 种手绘风格**、**166 种排版图型** 与 **36 款经典单色**，支持编号搜索、作者搜索与分类过滤。
   - **文生图 (Text-to-Image)**：自动组装中英双语、无污染的工业级标准提示词，调用大模型秒级出图。
   - **图生图 / 智能改图 (Image-to-Image / Edit)**：一键将已生成插画或本地照片作为底图，输入微调指令重绘修改。
   - **跨媒介风格融合 (Dual Style Fusion)**：自动遵循微缩摄影反差与造型解耦契约，支持“手绘角色 × 真实场景”融合出图。
   - **本地离线图库**：所有生成的画作自动持久化保存在本地 `client/history/`，原图永久留存。

2. **💎 极致美学与交互体验**
   - 雅致的手绘纸质温润质感（Warm Paper）与极客深邃暗夜（Dark Studio）一键切换。
   - 现代双栏自适应工作台，卡片悬浮高光、骨架呼吸灯与实时生图倒计时。

3. **🚀 参照 Codex 的更新机制**
   - 启动时自动异步比对远端版本。
   - 发现新版本时，顶部导航栏展示优雅闪烁的更新徽章。
   - 弹窗展示新版本更新日志，支持 **一键点击自动升级 (One-click Upgrade)**。

4. **🤝 丰富的中转站与赞助商生态（参照 magpie）**
   - 预设国内免翻墙、极速低价的精选中转商（如 **零词元 ZeroToken**、**硅基流动 SiliconFlow** 等）。
   - **专属福利与返佣通道**：内置作者专属邀请注册链接，为用户提供免费额度与折扣，为作者沉淀持续拉新赞助收益。
   - **自由中转兼容**：支持任意兼容 OpenAI `/v1` 协议的第三方 OneAPI / NewAPI 自定义网关。

## 🚀 极速启动方式

### Windows 用户（推荐）
在项目根目录或 `client/` 目录下，直接**双击运行**：
```bat
启动客户端.bat
```
客户端将自动启动本地服务并弹出浏览器窗口，访问地址为：`http://127.0.0.1:8765`。

### macOS / Linux 用户
在终端运行：
```bash
bash client/start.sh
```

## 🛠️ 目录架构说明

```text
client/
├── index.html                 # 客户端主界面 (SPA)
├── css/
│   └── app.css                # 视觉样式系统 (纸质温润风 + 暗黑极客风)
├── js/
│   ├── app.js                 # 主控制器与视图交互
│   ├── gallery.js             # 画廊检索、分类、色彩与图型选择器
│   ├── prompt-builder.js      # 标准手绘/排版/配色/融合提示词组装引擎
│   ├── generator.js           # API 生图、改图、底图管理与历史库
│   ├── settings.js            # 官方与第三方中转商/赞助商管理
│   └── updater.js             # Codex 风格升级检测与一键热升级
├── history/                   # 本地生成的画作原图与元数据存档 (自动创建)
├── server.py                  # 零依赖 Python 本地 HTTP/API 服务
├── version.json               # 客户端版本与更新日志
├── partners.json              # 预设合作伙伴与返佣拉新配置
├── 启动客户端.bat              # Windows 一键启动脚本
└── start.sh                   # macOS/Linux 启动脚本
```
